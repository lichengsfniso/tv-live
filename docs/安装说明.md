# TV Live — 安装说明

从 OneTV 桌面应用中单独剥离出来的电视直播 APK。内置央视频道（含加密流解密）、自定义 m3u 节目源、频道收藏、清晰度切换、数字选台、线路记忆等完整直播能力，并新增**信号源自动更新**。

## 一、选择哪个 APK

| 文件 | 适用设备 | 大小 |
|---|---|---|
| `TV_Live_arm64-v8a.apk` | **64 位设备**（绝大多数近 5 年的电视/盒子/投影）| 13.70 MB |
| `TV_Live_armeabi-v7a.apk` | 32 位老设备 | 14.35 MB |
| `TV_Live_通用版.apk` | 不确定设备架构时选这个，含两套原生库 | 17.59 MB |

> 不确定选哪个就用**通用版**。通用版 MD5：`5fbefeafc296f6c2da0e4e5aae971e1b`

## 二、安装

1. 把 APK 拷到 U 盘，插到电视/盒子上，用设备自带的文件管理器或"应用安装"打开安装；
2. 或通过局域网 ADB：`adb install TV_Live_通用版.apk`；
3. 首次安装需在系统设置里允许"安装未知来源应用"。

本应用包名是 `com.onetv.live`，**可以和原 OneTV 桌面同时安装，不会冲突**。

## 三、使用

- 安装后在电视桌面（Android TV 主屏）找到"TV Live"图标（深色圆角方形底 + 白色电视屏与播放三角，网页介绍页同款黑白简约图标），点击即可打开；冷启动会自动播放上次观看的频道。
- 遥控器操作：方向键选台/打开频道抽屉，数字键直接输入频道号，菜单键调出设置，返回键逐层退出。
- 首次使用若没有频道源，会弹出设置对话框，可导入 m3u 节目单文本、添加直播源（名称+URL）或订阅 URL。
- 内置央视频道随 App 自带，开箱即用（依赖官方接口，见下方注意事项）。

## 四、信号源自动更新（本次新增）

默认已开启，无需手动干预：

- **订阅源自动刷新**：默认每 6 小时在后台刷新已订阅的 m3u/订阅源，刷新过程不改变当前正在观看的频道，频道改名时收藏自动继承。
- **在线频道表（可选）**：默认只用 App 内置频道表。如需托管自己的频道表，在「更新设置」里填入公网 JSON 地址即可自动拉取；留空则不产生任何网络请求。JSON 需含 `schema` / `version` / `channels` 字段并带 sha256 校验，详见 `architecture-autoupdate.md`。
- **播放失效自动恢复**：中央接口 403/404 或流失效时自动清缓存、退避重连，并记忆实际成功的线路。

设置入口：直播界面按**菜单键 → 更新设置**，可配置自动刷新开关、间隔（6/12/24 小时或仅手动）、仅 WiFi 刷新，以及"立即检查更新""清除流缓存并重试"。

## 五、重要注意事项

1. **央视频道的稳定性依赖官方私有接口**：直播鉴权签名由央视频服务端与内置原生库 `libyangshipin.so` 共同决定。若官方变更接口/签名算法，内置央视频道可能失效——这是此类应用的固有维护成本，需要拿到新版原生库才能修复。已内置 CCTV 备用线路（`vdnx.live.cntv.cn`）作为兜底。**自定义 m3u 源不受此影响。**
2. **仅支持 arm 架构**：原生库只提供 arm64-v8a 与 armeabi-v7a，x86 设备/模拟器无法播放加密频道。
3. 本包为 **debug 签名版**，可直接安装使用；如需上架应用商店需另行制作 release 签名包。
4. 源码工程位于 `onetv-live-apk/`，可用 Android Studio 打开重新编译。
